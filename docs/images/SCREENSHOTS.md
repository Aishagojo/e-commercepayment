# README screenshots

Place the portfolio screenshots in this directory:

- `storefront.png`
- `lightning-checkout.png`
- `polar-network.png`
- `polar-payment.png`
- `payment-received.png`

Before capturing screenshots:

- Use regtest only.
- Hide terminal usernames and unrelated windows.
- Never expose seeds, passwords, macaroons, TLS keys, or `.env` values.
- Showing `lnbcrt...` invoices and node public keys is safe, but a clean crop is
  easier for reviewers to understand.
- Use the same browser size and theme for a consistent gallery.

After adding the screenshots, remove the HTML comment around the gallery image
links near the top of `README.md`.
